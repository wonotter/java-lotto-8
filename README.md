## 각 클래스 별 역할

> 각 클래스 별로 담당하고 있는 역할에 대해 작성하였습니다.

| 클래스명                  | 역할                                                                          |
|-----------------------|-----------------------------------------------------------------------------|
| Application           | 애플리케이션의 진입점으로 의존성을 주입하고 컨트롤러를 실행                                            |
| LottoController       | 입력 → 처리 → 출력의 흐름 관리, 사용자가 잘못 입력 시 재입력할 수 있도록 처리                             |
| InputView             | 구입금액, 당첨번호, 보너스번호 입력 처리                                                     |
| OutputView            | 로또 번호, 통계, 수익률 등을 포맷팅하여 출력                                                  |
| LottoRank             | 1~5등, 낙첨을 표현하고, 상금 정보를 함께 저장<br/>-> 일치 개수와 보너스 여부로 등수 판정                    |
| LottoStatistics       | 각 등수별 당첨 개수 집계 및 수익률 계산                                                     |
| Lotto                 | 개별 로또 티켓을 표현하며, 6개 번호를 저장                                                   |
| LottoTickets          | 여러 개의 `Lotto` 클래스를 관리하는 일급 컬렉션                                              |
| PurchaseAmount	       | 구입 금액을 표현하는 VO 객체이며, 금액 유효성 검증 및 티켓 개수 계산                                   |
| WinningNumbers        | 당첨 번호 6개를 표현하는 VO 객체이며, 입력 파싱 및 유효성 검증, 일치 개수 계산                            |
| BonusNumber           | 보너스 번호를 표현하는 VO 객체이며, 당첨 번호와 중복 방지 검증                                       |
| WinningLotto          | 당첨 정보인 `WinningNumbers`, `BonusNumber`를 묶어서 관리하는 객체 <br/> -> 티켓과 비교하여 등수 판정 |
| LottoGenerator        | 로또 번호 생성 전략을 정의한 인터페이스                                                      |
| DefaultLottoGenerator | 랜덤 로또 번호 생성 기본 구현체. 1~45 중 6개 무작위 선택                                        |
| ErrorMessage          | 에러 메시지를 중앙에서 관리하는 클래스                                                       |

## 기능 목록

> 구현할 기능 목록을 정리하였습니다.

### 1. 입력 기능

#### 구입 금액 입력

- [x] 로또 구입 금액을 `1,000원` 단위로 입력받는다.

  ```text
  8000
  ```

#### 당첨 번호 입력

- [x] 구입 금액을 입력해 달라는 안내 문구를 출력한다.
- [x] 당첨 번호를 `쉼표(,)` 기준으로 입력받는다.
- [x] 당첨 번호의 숫자 범위는 `1 ~ 45` 사이이다.
- [x] 당첨 번호의 숫자는 서로 중복되지 않아야 한다.

  ```text
  구입금액을 입력해 주세요.
  1,2,3,4,5,6
  ```

#### 보너스 번호 입력

- [x] 보너스 번호를 입력해 달라는 안내 문구를 출력한다.
- [x] 보너스 번호를 입력받는다.
- [x] 보너스 번호 숫자 범위는 `1 ~ 45` 사이이다.
- [x] 보너스 번호 숫자와 당첨 번호 숫자는 서로 중복되지 않아야 한다.

  ```text
  보너스 번호를 입력해 주세요.
  7
  ```

### 2. 로또 발행 및 당첨 확인 기능

#### 로또 발행

- [x] 로또 구입 금액을 입력하면 구입 금액에 해당하는 수량만큼 로또를 발행하며, 1장 가격은 `1,000원` 이다.
- [x] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.

#### 당첨 확인

- [x] 당첨은 1등부터 5등까지 있으며, 당첨 기준과 금액은 다음과 같이 적용한다.
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원

- [x] 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 계산한다.

### 3. 출력 기능

#### 구매한 로또 출력

- [x] 발행한 로또 수량 및 번호를 오름차순으로 정렬하여 출력한다.
- [x] 출력 형식은 `대괄호 []` 안에 `쉼표(,)`를 기준으로 번호를 출력한다.

  ```text
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43] 
  [3, 5, 11, 16, 32, 38] 
  [7, 11, 16, 35, 36, 44] 
  [1, 8, 11, 31, 41, 42] 
  [13, 14, 16, 38, 42, 45] 
  [7, 11, 30, 40, 42, 43] 
  [2, 13, 22, 32, 38, 45] 
  [1, 3, 5, 14, 22, 45]
  ```

#### 당첨 내역 출력

- [x] 당첨 내역 횟수를 카운트하여 출력한다.

  ```text
  당첨 통계
  ---
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  ```

#### 수익률 출력

- [x] 수익률은 `(당첨 금액 / 구매 금액) x 100 (%)`로 계산한다.
- [x] 소수점 둘째 자리에서 반올림한다.

  ```text
  총 수익률은 62.5%입니다.
  ```

## 예외 처리 목록

> 발생 가능한 예외 상황과 처리 방법을 정리하였습니다.

### 0. 예외 처리 공통사항

- [x] 예외 상황 발생 시 모든 에러 메시지는 `[ERROR]`로 시작하도록 하고, 예외가 발생한 지점부터 다시 입력받는다.

### 1. 입력 값 예외

- [x] 빈 문자열이나 null을 입력받을 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 당첨번호를 `쉼표(,)` 기준으로 입력받지 않는 경우 `IllegalArgumentException`을 발생시킨다.

### 2. 구입 금액 예외

- [x] 로또 구입 금액이 `1,000원` 단위로 나누어 떨어지지 않는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 로또 구입 금액이 int 범위를 벗어나거나 유효한 숫자 형식이 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 로또 구입 금액이 0보다 작은 경우 `IllegalArgumentException`을 발생시킨다.

### 3. 당첨 번호 예외

- [x] 당첨 번호 숫자 범위인 `1~45`를 벗어나는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 당첨 번호 숫자가 서로 중복되는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 당첨 번호가 int 범위를 벗어나거나 유효한 숫자 형식이 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 당첨 번호 개수가 6개가 아닌 경우 `IllegalArgumentException`을 발생시킨다.

### 4. 보너스 번호 예외

- [x] 보너스 번호 숫자 범위인 `1~45`를 벗어나는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 보너스 번호와 당첨 번호가 서로 중복되는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 보너스 번호가 int 범위를 벗어나거나 유효한 숫자 형식이 아닌 경우 `IllegalArgumentException`을 발생시킨다.
